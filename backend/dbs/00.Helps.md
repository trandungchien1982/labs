Usage:
cd backend/dbs

# Start Postgres only
docker compose up -d postgres

# Run migrations (builds Flyway image first)
docker compose --profile migrate up flyway

# Rebuild after adding new SQL files
docker compose --profile migrate up --build flyway


The migration will run after V20260528000000__init_schema.sql thanks to Flyway's version ordering. Run it with:
cd backend/dbs
docker compose --profile migrate up --build flyway

docker compose up --build flyway
